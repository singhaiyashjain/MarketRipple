# Demo script (5 min)
1. **Problem (30s)** — headlines are isolated; impact is a chain.
2. **Input (20s)** — pick *Crude oil +12%* (label **Simulated Demo Event** unless verified).
3. **Extraction (30s)** — event, entity, change, driver; "we never invent numbers".
4. **Graph (45s)** — central oil node; solid = rule/verified, dashed = LLM-inferred.
5. **Path click (60s)** — Aviation path; show explanation + assumptions (hedging, pass-through).
6. **Quant moment (60s)** — click an edge: beta, t-stat, n, lag from history. "Co-movement, not causation."
7. **Sectors (30s)** — who loses AND who benefits (upstream oil).
8. **Honesty (30s)** — eval results, measured only. Close.
Fallback: if internet dies, `FORCE_MOCK=true` / cached events.
